原 IndexedDB 保持同名，版本 4 新增 `csAnswers` 和 `csAnswerPhotos`，作答不自动收录错题；新数据与作答图片加入本机同步、ZIP 版本 1 备份、恢复和历史快照。旧备份缺少新增数组时仍可恢复，旧浏览器同步未携带新增表时服务端保留现有数据。所有项目文件仅保存在当前目录。

本机运行的 BPhO Round 1、Edexcel FP1 与 S2 训练网站。React + TypeScript + Vite，训练、照片及订正自动同步到项目 `data/`，浏览器 IndexedDB 保留本地副本，运行时不调用云服务。

## 打开网站

1. 双击项目中的 `start.cmd`。
2. 浏览器会打开 **http://127.0.0.1:4173/**。服务在后台运行，启动窗口可关闭。
3. 启动程序会登记当前用户的 Windows 登录自动启动任务 `BPhO-Study-Local`；网站进程异常停止后数秒重启，后台守护程序整体停止时由每分钟恢复检查重新启动。重复打开入口不会创建多份服务。运行日志保存在 `data/service/service.log`。
3. 始终使用这个地址。本机不同浏览器会自动同步记录；等待“已同步”后再切换。不要双击 `dist/index.html`。

项目内包含已构建的 `dist` 和 `runtime/node.exe`，正常使用不需要安装依赖或其他运行程序。所有项目文件保存在本目录，今后只维护本机运行版本，不向桌面输出或制作分享版。

## 使用方式

- **最高分与分数统计**：主界面每张试卷显示本机已完成批改的最高分；条形图按训练开始的本地时间排列，标注试卷年份、得分和满分。支持按年份、试卷筛选，点击最高分或柱子进入对应训练；未批改和旧版整卷记录不计入。
- **交卷检查与快捷批改**：交卷确认框列出未标记完成的题号，可直接返回检查。电脑宽屏并排显示题目与答案，底部固定快捷得分、错题选择和切题按钮；手机保持顺序展示。
- **备份提醒**：数据页显示本浏览器上次发起 ZIP 备份导出的时间（仍需自行确认下载已保存）。新增 5 次完成训练、10 张图片，或有变更且距上次导出满 7 天时，首页提示备份，可延后 7 天。导出时间及提醒偏好仅在当前浏览器保存，不改变 ZIP 格式。
- **真题题库**：按年份和 Section 选择。Section 2 按原卷选做规则选择大题；2016 年第 5、6 题互斥。
- **训练**：Section 1 按 A → B → C → D…逐题展示，每个字母题内部的 (i)、(ii) 保留在同一题；Section 2 按原大题展示。支持切题和完成标记。计时不暂停，关闭浏览器后的间隔也会计入。整场交卷固定用时。
- **做题全宽界面**：三科训练和批改时隐藏全站侧栏及科目切换，左上角保留“〈 退出”。点击返回主页，题目位置、批改草稿和记录保留，未交卷训练继续计时；主页仍显示完整导航。S2 题号与统计表继续放在题目左侧。
- **批改**：每页依次显示本题题目、标准答案、得分、加入错题本选项、解答/更正照片、下一题。必须填写有效得分才能前进或返回上一题；支持小数。
- **照片**：两个过程区域分别上传多张图，支持旋转、放大、删除；上传完成后才允许切换批改题目。支持 JPG、PNG、WebP、GIF、AVIF、BMP，单张不超过 25 MB；HEIC 需先转 JPG。
- **订正**：可以稍后补图，新增订正不覆盖旧版；说明文字点击“保存说明”。逐题得分及本题笔记自动保存草稿。
- **记录**：每次重练单独保留；同一道错题合并展示多个训练关联。已完成训练可点进回看并修改批改结果。
- **备份**：在“数据与备份”导出 ZIP，内含全部个人记录和照片。恢复先验证再原子合并，重复导入不复制；同 ID 的训练/订正保留较新的版本，已有图片保持本机版本。合并出现两场未交卷训练时拒绝整次恢复。

## 数据保护

## S2 做题查表

S2 主页也提供“统计查表”入口，点击 Binomial、Poisson 或 Normal 即可打开大图查表，不需要开始训练；支持切换、翻页和缩放，并沿用上次查表设置。

S2 训练页左侧提供教材原版 Binomial 二项分布累计概率表（书第 139–143 页）与 Poisson 泊松分布累计概率表（书第 144 页）。可切换表格、翻页、缩放和滚动，点击“放大”查看大图；手机上可展开或放大。查表不暂停计时，不显示试卷答案，切题、刷新后保留上次的查表选项。BPhO 和 FP1 页面不增加该区域。

原书为 `新增内容/S2.pdf`，静态表图保存在 `public/s2-reference/`；`scripts/extract_s2_tables.py` 提取原始扫描图，只裁去页眉和空白，未重录数值。核对信息见同目录 `tables.json`。

同一区域另有 **Normal 标准正态分布表**，按 Φ(z) = P(Z ≤ z) 显示 z = 0.00–3.99 的累计概率，保留四位小数；负值使用 Φ(−z) = 1 − Φ(z)。正态表为可选中文字的表格，行列标题在滚动时固定。数值通过 `scripts/build_normal_table.py` 使用误差函数计算，保存在 `src/normal-table.json`，不冒充教材原页。

## S2 Critical region 专项测试

在 S2 主页点击“打开专项测试”，自行选择 Binomial／Poisson、Real（不超过 sig）／As close as possible、单尾（上尾或下尾）／双尾，以及 5%／10%。每次生成一道所选类型的题，分布参数随机；“再来一次”保持本题类型。双尾分别对照 sig／2。只使用教材表内参数，以精确离散概率判分，并排除空临界域和表格四位小数造成的歧义题。

电脑左侧自动显示对应的完整教材表格页，按屏幕高度适配，点击可放大；右侧填写整数边界。答对后结算用时，可“再来一次”；答错显示标准临界域及相邻概率。退出、刷新后可继续，未提交前连续计时，提交后固定。设置页下方可查看每次题型、正确／错误、用时和答案；专项记录独立于模考成绩和错题本。

专项记录保存在原数据库新增的 `criticalAttempts` 表，并自动同步到项目 `data/`。ZIP 仍为版本 1，新增可选的同名字段，兼容没有该字段的旧备份。模考可独立继续计时；专项不提交或暂停模考。

## 本机浏览器同步说明

使用 `start.cmd` 启动后，GPT 内置浏览器和其他本机浏览器访问同一个固定地址，会自动合并已有记录并同步训练、逐题得分、错题、照片、旋转和订正。首次启用时需在有旧记录的浏览器中刷新一次，等待显示“已同步”。其他浏览器独有记录也会导入，不需要手工转移 ZIP。

共享元数据保存在 `data/study-data.json`，图片保存在 `data/photos/`。前一次保存和初次迁移副本也保存在 `data/`。请完整保留该文件夹；停止服务后可以复制整个文件夹作为本机副本。个人 ZIP 备份格式与旧版一致。

服务断开时，原有训练与批改仍可在当前浏览器保存，恢复连接后自动重试；新开训练前需要连接同步服务，防止两个浏览器同时开卷。同一字段并行修改会提示选择保留此浏览器或共享版本，其他字段自动合并。两份冲突副本保留在浏览器内部恢复信息中。首次合并若发现两场旧的未交卷训练，两场计时均保留，可在训练记录中分别继续交卷。

科目偏好、搜题选项和备份提醒仍是各浏览器的个人界面设置。同步限同一台电脑，不是跨设备或云同步。开发时仅启动 Vite 没有共享接口，日常请使用 `start.cmd`。

## 搜题

导航栏“搜题”提供联动下拉选项：BPhO 为年份、Section、题号；FP1、S2 为年份、月份、题号。
题号按实际试卷提供，切换年份时保留对应的 Section／月份、卷别及题号；仅新试卷不存在的选项会清空。已展示的结果随之切换为新试卷。搜题始终显示现有答案，包括正在训练的试卷；训练页面仍在整场交卷后显示答案。
结果包含题目、评分细则和该题全部训练记录（包含未加入错题本的训练），按准确的试卷 ID 与题目 ID 关联。
每条记录显示完整训练日期、整场用时、状态、已记录得分、笔记及实际错题收录状态；未评分不会显示为 0 分。
可展开查看该次解答、更正图片与说明，后续订正单独列出。搜题中的图片查看为只读，保留已有旋转方向。
旧版整卷记录仅作为相关历史入口，不分摊成绩、不计入字母题训练次数。缺答案题目仍可查阅原题。
查看整场训练或错题详情后，可点击“返回搜题结果”；查询选择和已展示结果会按科目保存在当前浏览器，刷新或关闭后再次打开仍可恢复。
搜题结果可直接加入错题本，无需创建训练或填写分数；可在错题详情补充过程图片和订正。手动收录会随个人 ZIP 备份保存，沿用原有数据库和备份格式。

验证：`pnpm test`、`node scripts/e2e-search.mjs`（启动网站后运行）。

## S2 独立文字题合集（2014–2026）

S2 题库页的“主观题合集”覆盖本项目提供的 38 套试卷（含 3 套 A 卷），逐卷核查 1,026 个原卷小问，收录 148 道独立文字小问。与现有整卷模考题库分别维护；专题用于查阅，不创建训练、得分或错题记录。

- 收录独立编号的解释、概念、模型假设、抽样评价、近似条件、假设陈述和情境结论。纯数值计算、作图、推导以及计算和文字同号的混合问不收录。
- 前置计算小问只作为理解背景，不计入题数。题目重复出现时按原场次全部保留。
- 原卷扫描件采用 Windows OCR 辅助，显示内容始终取自原 PDF 图像。对原卷合并给分的小问，依据对应独立 B1 评分点核实分值，不直接套用整组总分。
- 网站支持知识点、年份、月份和卷别筛选，原题放大、逐题展开答案，以及 PDF 和 CSV 核查清单下载。
- 两册 PDF 与核查资料在 `output/pdf/`，网站下载副本在 `public/s2-written/downloads/`。所有 148 个合集编号与网站一致。

可复现流程：使用带 PyMuPDF 的 Python 运行 `scripts/s2_written_extract.py`、`scripts/s2_written_parse.py`、`scripts/build_s2_written.py --assets`、`scripts/print_s2_written.py`、`scripts/audit_s2_written.py`。项目内 Python 依赖在 `runtime/python-packages`，扫描页识别需要 Windows OCR。`scripts/s2_written_selection.json` 是逐卷人工核查后的收录清单。完整逐小问决策及源 PDF 哈希随输出保存，所有 PDF 页面均渲染到 `tmp/qa/s2-written/` 供复核。

浏览器验收：`runtime/node.exe scripts/e2e-s2-written.mjs`。运行中的网站继续使用 `http://127.0.0.1:4173/`，原三科训练及个人备份兼容。
